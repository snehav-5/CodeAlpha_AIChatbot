# CodeAlpha AI Chatbot

## Description

A simple Java-based rule-driven chatbot that interacts with users through the console.

## Features

* Greeting responses
* Basic question handling
* Java-related responses
* Help option
* Exit command

## Technologies Used

* Java
* Scanner
* Conditional Statements
* String Handling

## How to Run

Compile:
`javac AIChatbot.java`

Run:
`java AIChatbot`
